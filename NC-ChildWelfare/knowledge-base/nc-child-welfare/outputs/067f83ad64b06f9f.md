Also attached you will find an updated Central Registry Report User Manual and Report to Central Registry DSS form 5104. These attachments reflect changes required by the implementation of the Responsible Individuals List.

The User Manual provides instruction on completing the new DSS-5104:

Field 26. Contributory Factors.

A new block has been added that allows social workers to identify caretaker lack of child development knowledge as contributing the finding. Please refer to page 18 and 19 of the user manual for more detailed information.

Field 31. Maltreatment Type Found

A new column has been added that allows the social worker to identify the neglect type found as serious if applicable by individual perpetrator. Please refer to page 26 of the user manual for more detailed information.

Field 38. Responsible Individuals List

This new field allows the social worker to identify the perpetrator as being responsible for the abuse or serious neglect of a child. It is this field that places the individual's name on the responsible individuals list. Information from this list can be requested by authorized employers and others who need to determine the individual's fitness to care for children. Placement on the responsible individuals list determines eligibility for the expunction process. Please refer to page 30 and 31 of the user manual for more detailed information.

This change is effective for all cases received on or after May 01, 2006. Social workers should complete all fields on the DSS-5104 with a revision date of 05/06. The automation system that manages the central registry and the Responsible Individuals List is not yet ready to receive this additional data. The anticipated date for the automation system to be online with these changes is June 15, 2006. Therefore, when data entry staff enter data into the CPS Central Registry System they will not see the new block in Field 26, or the serious neglect blocks in Field 31, and or field 38, until June 15, 2006. Data entry staff should enter all of the information with the exception of these three additions.
