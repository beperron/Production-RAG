### CHANGE NOTICE FOR MANUAL

DATE: FEBRUARY 15, 2017 MANUAL: Chapter IV: Child Placement and Payment System CHANGE NO: 02-2017 TO: COUNTY DIRECTORS OF SOCIAL SERVICES / HUMAN SERVICES ATTENTION: CHILD WELFARE PROGRAM MANAGERS & SUPERVISORS CHILD WELFARE SOCIAL WORKERS RE: Revision to Chapter IV: Child Placement and Payment System regarding Foster Care 18 to 21. EFFECTIVE: Immediately

I. BACKGROUND | CHANGE INTENT

The Child Placement and Payment System (CPPS) Manual has been updated to incorporate the changes needed for the implementation of Extended Foster Care (Foster Care to 21). The specific changes for Extended Foster Care are listed in Section II of this notice. The CPPS system has been updated to capture the information shown in Section II for Extended Foster Care as well as information on Human Trafficking, Runaway, and Non-Family Placement Settings for children in care. The CPPS manual was previously updated to include the material for Human Trafficking, Runaway, and Non-Family Placement Settings (See CWS-CN-02-2015 https://www2.ncdhhs.gov/info/olm/manuals/dss/csm-10/chg/CWS-CN-02-2015.pdf ), however the changes had not been made to the system at that time. The changes related to Human Trafficking, Runaway, and Non-Family Placement Settings required the creation of multiple new fields in the CPPS system. For this reason, an updated DSS-5094 has been created, as well as a continuation page, the DSS-5094c. Both these forms are available on the DSS forms website. A User's Guide has been created to assist when keying new DSS-5094 and DSS-5094c forms into CPPS. The User's Guide differs from the CPPS manual in that it provides more detailed instruction on the navigation between screens rather than the valid values for each field. A copy of the User's Guide is attached to this change notice.
